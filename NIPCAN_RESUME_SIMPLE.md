# 🔑 NIPCAN - Résumé Simple

## Qu'est-ce que c'est ?

Le **NIPCAN** est comme un **numéro de sécurité sociale** pour les candidats.
- Créé **UNE SEULE FOIS** lors de la première inscription
- Utilisé pour **TOUTES** les candidatures futures
- Permet de se **connecter** au dashboard

---

## 📅 Quand est-il créé ?

### Scénario 1 : Premier candidat (Jean)

```
Jean s'inscrit au concours ENS
         ↓
Remplit le formulaire
         ↓
Clique sur "Soumettre"
         ↓
🎉 NIPCAN créé : NIP2026000001
         ↓
Email reçu avec le NIPCAN
         ↓
Jean peut se connecter
```

### Scénario 2 : Deuxième candidature (Jean)

```
Jean veut s'inscrire au concours ENSP
         ↓
Remplit le formulaire
         ↓
Son NIPCAN est déjà dans le système
         ↓
♻️ Réutilise : NIP2026000001
         ↓
Nouvelle candidature créée
         ↓
Même NIPCAN, nouveau NUPCAN
```

---

## 🔢 Format du NIPCAN

```
NIP  2026  000001
 │    │      │
 │    │      └─ Numéro séquentiel (1er candidat = 000001)
 │    └──────── Année d'inscription
 └───────────── Préfixe fixe
```

### Exemples
- Premier candidat 2026 : `NIP2026000001`
- Deuxième candidat 2026 : `NIP2026000002`
- Centième candidat 2026 : `NIP2026000100`
- Premier candidat 2027 : `NIP2027000001`

---

## 🎯 À quoi ça sert ?

### 1. Se Connecter
```
Page de connexion
  ↓
Saisir NIPCAN
  ↓
Accès au dashboard
  ↓
Voir toutes ses candidatures
```

### 2. Multi-Candidature
```
Un candidat = Un NIPCAN
Plusieurs concours = Plusieurs NUPCAN
Même NIPCAN pour tout
```

### Exemple Concret
**Marie MBONGO**
- NIPCAN : `NIP2026000005` (permanent)
- Candidature ENS : NUPCAN `20260115-3`
- Candidature ENSP : NUPCAN `20260120-8`
- Candidature ENAM : NUPCAN `20260125-2`

Marie se connecte avec `NIP2026000005` et voit ses 3 candidatures.

---

## 📧 Comment le recevoir ?

### Lors de l'inscription
1. Remplir le formulaire de candidature
2. Soumettre
3. Recevoir un email :

```
Sujet : Confirmation d'inscription

Bonjour Marie,

Votre NIPCAN : NIP2026000005

Conservez-le précieusement !
Vous en aurez besoin pour :
- Vous connecter
- Créer d'autres candidatures
```

---

## ⚠️ Important à Savoir

### ✅ À FAIRE
- Conserver son NIPCAN en lieu sûr
- L'utiliser pour toutes les candidatures
- Se connecter avec pour voir ses dossiers

### ❌ À NE PAS FAIRE
- Partager son NIPCAN avec d'autres
- Créer plusieurs comptes (un seul NIPCAN suffit)
- Oublier son NIPCAN (noter dans un endroit sûr)

---

## 🔍 Où le trouver ?

### Si vous l'avez perdu
1. Chercher dans vos emails (sujet : "Confirmation d'inscription")
2. Contacter l'administration avec :
   - Votre nom complet
   - Votre email d'inscription
   - Votre numéro de téléphone

- Permet d'accéder à votre compte

- Utilisé pour tous vos voyages

## 📊 Différence NIPCAN vs NUPCAN

| Aspect | NIPCAN | NUPCAN |
|--------|--------|--------|
| **Signification** | Numéro Identification Permanent | Numéro Unique Candidature |
| **Création** | Une fois (1ère inscription) | À chaque candidature |
| **Usage** | Connexion + Identification | Suivi d'une candidature |
| **Exemple** | NIP2026000001 | 20260115-3 |
| **Permanence** | Permanent (à vie) | Temporaire (par concours) |

### Exemple Visuel
```
Jean DUPONT
├─ NIPCAN: NIP2026000001 (permanent)
│
├─ Candidature ENS
│  └─ NUPCAN: 20260115-1
│
├─ Candidature ENSP
│  └─ NUPCAN: 20260120-5
│
└─ Candidature ENAM
   └─ NUPCAN: 20260125-3
```
